# Sales Alchemist — Solutions Engineer Portfolio

Personal portfolio for Solutions Engineering work — case studies, toolkit, and contact.

## Tech Stack

- **React 18** + **Vite**
- **Tailwind CSS**
- **Framer Motion**
- **Lucide React**
- **React Router v6**

## Prerequisites

- Node.js 18+ and npm

## Setup

```bash
npm install
npm run dev
```

The dev server runs at `http://localhost:5173`.

## Build

```bash
npm run build
npm run preview
```

## Sections

1. **Navbar** — sticky, scroll-aware with mobile drawer + live local time
2. **Hero** — intro with split-character reveal and magnetic CTAs
3. **About** — bio, stat counters (PoCs delivered, customer wins)
4. **Selected Wins** — anonymized customer case studies
5. **Toolkit** — integration, pre-sales, and code categories
6. **Contact** — email and LinkedIn with copy-to-clipboard
7. **Footer** — minimal index + wordmark

## Deployment

Configured for zero-config deployment on **Vercel**. Push to `main` and Vercel auto-deploys.
